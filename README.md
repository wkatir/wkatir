## What I build

**AI systems.** LLM agents and multi-agent systems, RAG over private data with evaluation
and per-query cost tracking, MCP servers connecting agents to internal APIs and databases.

**Backends and infrastructure.** Python, TypeScript, FastAPI, AWS Lambda, DynamoDB,
Cloudflare Workers, Terraform, Docker, CI/CD.

**Bitcoin.** Self-custody with Miniscript and timelocks, multi-party signing with FROST,
Lightning payments (BOLT12, LnURL, Breez SDK), Liquid and RGB.

**Full-stack when the team needs it.** React, Next.js, PostgreSQL, MongoDB.
